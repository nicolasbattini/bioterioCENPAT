# Bioterio CCT CONICET-CENPAT
En este repositorio se encuentra el código del sistema de monitoreo de temperatura del Bioterio del CCT. 
Este sistema consiste en módulos Nodemcu ESP8266 V3.0 y termistores DS18B20 que sensan la temperatura del agua dentro de la sala principal y la cámara fría, y la reportan a una hoja de cálculo de Google de la cuenta comisionacuariocenpat@gmail.com.
Esto se logra mediante una implementación de Appscript en Google, y un programa en C++ de Arduino.
